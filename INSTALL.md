# Как поставить Kentik на iPhone

Kentik нет в App Store. Его ставят бесплатно через **AltStore** или **Sideloadly** с обычным
Apple ID — платный аккаунт разработчика не нужен. Бесплатная подпись Apple действует
**7 дней**: AltStore продлевает её сам, Sideloadly — повторной установкой.

Нужно: iPhone с iOS 17 или новее, компьютер с Windows, кабель USB.

Адрес источника Kentik для AltStore:

```
https://raw.githubusercontent.com/nadjafchurkovod123/kentik-ios/main/altstore/source.json
```

---

## Вариант 1. AltStore (рекомендую — обновления Kentik приходят сами)

### 1. Подготовить компьютер

1. Установите **iTunes** и **iCloud с сайта apple.com**, а не из Microsoft Store.
   AltServer не видит iPhone через версии из Microsoft Store. Если они уже стоят, удалите
   их. Прямые ссылки на подходящие версии есть в инструкции AltStore для Windows на
   [altstore.io](https://altstore.io) («How to install AltStore — Windows»).
2. Скачайте **AltServer для Windows** с [altstore.io](https://altstore.io), распакуйте архив
   и запустите `Setup.exe`. Затем запустите AltServer: его значок (ромб) появится в трее
   у часов.
3. Подключите iPhone кабелем. На iPhone нажмите «Доверять этому компьютеру» и введите
   код-пароль.
4. Откройте iTunes, выберите iPhone и включите **«Синхронизировать с этим iPhone по
   Wi‑Fi»**, затем «Применить». Без этого AltStore не сможет продлевать подпись по Wi‑Fi.

### 2. Поставить AltStore на iPhone

1. Нажмите на значок AltServer в трее → **Install AltStore** → ваш iPhone.
2. Введите Apple ID и пароль. Подойдёт обычный бесплатный Apple ID. Лучше завести
   отдельный, не основной. Данные уходят только на серверы Apple.
3. На iPhone откройте «Настройки» → «Основные» → «VPN и управление устройством». Выберите
   профиль со своим Apple ID и нажмите **«Доверять»**.
4. Включите **режим разработчика**: «Настройки» → «Конфиденциальность и безопасность» →
   «Режим разработчика» (в самом низу) → включить. iPhone перезагрузится, после этого
   подтвердите «Включить». Пункт появляется только после установки AltStore.
5. Откройте AltStore → вкладка **Settings** → войдите тем же Apple ID.

### 3. Поставить Kentik

1. В AltStore откройте вкладку **Sources** (или Browse → Sources) и нажмите **«+»**.
2. Вставьте адрес источника (он в начале страницы) и подтвердите.
3. Откройте источник **Kentik** и нажмите **Free** / **Install**. Kentik появится на
   домашнем экране.
4. Новые версии появятся в AltStore → **My Apps** с кнопкой **Update**.

### Продление каждые 7 дней

- AltStore продлевает подпись сам, в фоне, когда **компьютер включён**, **AltServer
  запущен**, а **iPhone в той же сети Wi‑Fi**. Иногда открывайте AltStore — так продление
  идёт надёжнее.
- Вручную: AltStore → **My Apps** → **Refresh All**. Так же можно и по кабелю.
- Если 7 дней всё-таки прошли, Kentik перестанет открываться, но вкладки и настройки
  сохранятся. Подключите iPhone к компьютеру и нажмите **Refresh All**.
- Ограничения бесплатного Apple ID: одновременно не больше 3 своих приложений (AltStore
  и Kentik — это два) и не больше 10 новых App ID в неделю.

## Вариант 2. Sideloadly (без AltStore, обновлять вручную)

1. Установите iTunes и iCloud с сайта apple.com, как в пункте 1 выше.
2. Скачайте и установите **Sideloadly** с [sideloadly.io](https://sideloadly.io).
3. Скачайте **Kentik.ipa** со страницы последнего релиза:
   <https://github.com/nadjafchurkovod123/kentik-ios/releases/latest>.
4. Подключите iPhone кабелем и запустите Sideloadly. **Перетащите Kentik.ipa** в окно,
   введите Apple ID и нажмите **Start**. Пароль Apple ID Sideloadly спросит сам.
5. На iPhone: «Доверять» профилю и режим разработчика — как в шагах 3–4 раздела про
   AltStore.
6. Через 7 дней повторите установку тем же файлом: вкладки и настройки сохранятся. Если
   в вашей версии Sideloadly есть автоматическое продление, можно включить его.

---

## Полезно знать

- Kentik нельзя сделать браузером по умолчанию: для этого Apple требует платный аккаунт
  разработчика. Открыть ссылку в Kentik можно через Команды: `kentik://open?url=<адрес>`.
- Установка новой версии поверх старой сохраняет вкладки, историю и настройки.
  Удаление приложения стирает всё.
- Списки блокировки рекламы Kentik обновляет сам раз в сутки, без новой установки.
